# popfleet implementation notes

One line per non-obvious decision: what | why | alternative rejected. `DEVIATION:` marks spec departures.

- 2026-08-11 DEVIATION: state is JSON file + mutex (internal/store), not the SQLite named in the RDD architecture block | the resolved open question overrides it: "JSON+mutex is fine at this scale" | SQLite rejected: cgo or a third dep for a personal fleet.
- 2026-08-11 single proto.Msg struct for every frame on both sockets | tiny frozen protocol, omitempty keeps frames minimal | per-frame structs rejected as 12 types for 12 one-line frames.
- 2026-08-11 proto.Msg.Code is *int | exit code 0 must serialize; omitempty on plain int would drop it | always-emit int rejected: every non-exit frame would carry "code":0.
- 2026-08-11 machine id minted at token creation and persisted; hello looks up by token | enrollment token IS the durable identity, so reconnect keeps the same id with no re-enroll (Gate 3) | deriving id from connection rejected: id would churn per reconnect.
- 2026-08-11 admin bearer and session keys compared as sha256 sums via crypto/subtle.ConstantTimeCompare | constant-time equality that also hides length | direct ConstantTimeCompare on raw strings rejected: short-circuits on length mismatch.
- 2026-08-11 one-time session keys: crypto/rand, 60 s TTL, deleted at first valid upgrade under the broker mutex, 10 s sweeper for never-used expired keys | spec: first upgrade wins, expired/used keys must not leak | lazy-expiry-only rejected: unused keys would accumulate.
- 2026-08-11 broker gives every websocket (agent and browser) a bounded 256-frame outbound queue drained by one writer goroutine; queue-full to a browser kills THAT session with `{"t":"err"}` | a slow browser must never stall the shared agent socket (two `yes` firehoses + typing) | blocking writes rejected: deadlocks the relay; unbounded queues rejected: OOM under firehose.
- 2026-08-11 queue-full toward the AGENT drops the frame silently (keystrokes are tiny, 256 is deep) | ponytail: simplest non-blocking path; per-key retry if it ever matters | killing the whole agent conn for one full queue rejected as disproportionate.
- 2026-08-11 broker agent-read deadline 35 s (hb every 10 s, offline threshold 25 s) so a silently dead TCP conn is reaped and its sessions get err banners | requirement: losing the agent socket must never leave a dead black box | relying on TCP keepalive rejected: minutes of limbo.
- 2026-08-11 agent liveness via ws ping alongside each hb + pong handler extending a 45 s read deadline | broker sends nothing to an idle agent, so a plain read deadline would kill healthy idle conns; gorilla auto-pongs pings | broker-side keepalive frames rejected: protocol is frozen, no new tags.
- 2026-08-11 agent reconnect: 1 s doubling to 30 s cap with ±20% jitter, reset to 1 s only after a successful hello_ok | spec wording exactly; reset-on-dial rejected: a broker that accepts TCP but rejects hello would hammer at 1 s forever.
- 2026-08-11 duplicate agent connection for the same token replaces the old one (old sessions banner+die) | a NAT-zombied socket must not block reconnect (Gate 3) | rejecting the new conn rejected: locks the machine out until the zombie times out.
- 2026-08-11 dropAgent only reaps sessions when the dying conn is still the registered one | a replaced zombie dying later must not kill its successor's fresh sessions | naive by-machine-id cleanup rejected: race kills wrong sessions.
- 2026-08-11 browser session registered in the sid map BEFORE `open` is sent to the agent | first PTY bytes can arrive before the handler returns; registering after loses the prompt | post-open registration rejected: racy.
- 2026-08-11 CSP `style-src 'self' 'unsafe-inline'` on panel pages | xterm.js injects its layout stylesheet at runtime via a <style> element, which strict style-src blocks; scripts stay 'self'-only, no CDN/fonts/analytics/service worker | hashing the injected sheet rejected: content is computed at runtime, not hashable ahead of time.
- 2026-08-11 page JS lives in separate embedded files (index.js, term.js), not inline <script> | script-src 'self' forbids inline scripts and stays that way | 'unsafe-inline' for scripts rejected outright.
- 2026-08-11 panel go:embed lists files by name instead of embedding the vendor dir | stray non-asset files in vendor/ must never ship inside the binary | directory embed rejected.
- 2026-08-11 contrib/ is a tiny Go package (embed.go) embedding agent.sh so the broker serves GET /agent.sh | makes the RDD "wow moment" curl|sh block actually work from the panel with zero duplication | copying the script into internal/broker rejected: two sources of truth.
- 2026-08-11 agent.sh fetches the binary from GitHub releases (POPFLEET_BIN_URL overrides) | broker only serves the installer script, not per-arch binaries, and the module path gives a canonical home | serving binaries from the broker rejected for v1: multi-GB embed or extra operator setup.
- 2026-08-11 agent.sh on macOS keeps the token in ~/.popfleet.env (0600) and the launchd plist just sources it | launchd has no EnvironmentFile; putting the token in the plist would leak it to anything reading LaunchAgents | plist EnvironmentVariables rejected.
- 2026-08-11 Containerfile final stage is scratch with the static agent only, per the RDD "lean" resolution | ponytail: no shell inside means in-container terminal opens report exit 127; swap final stage to busybox:musl when an interactive container shell matters | distroless rejected: same no-shell ceiling, bigger image.
- 2026-08-11 login shell is `$SHELL -l` (fallback /bin/sh), `--cmd` runs `$SHELL -c cmd`, TERM=xterm-256color | boring and works on mac/linux | shells looked up via /etc/passwd rejected: $SHELL is right for a single-operator agent.
- 2026-08-11 store.Touch persists on every heartbeat (one atomic file write per agent per 10 s) | last_seen must survive broker restart; write volume is trivial at personal-fleet scale | debounced writes rejected as premature.
- 2026-08-11 broker default port 7333 | 8080 collides with everything a developer runs | (none).
- 2026-08-11 machine goes online:false when socket is gone OR last_seen > 25 s, whichever first; panel polls /api/machines every 2 s and diffs online sets for join/leave toasts | spec: two missed heartbeats; the socket check catches clean exits instantly (podman rm demo) | pure timestamp check rejected: clean disconnects would show green for 25 s.
- 2026-08-11 DEVIATION: Containerfile final stage switched scratch -> busybox:musl (~4 MB), ENV SHELL=/bin/sh | the RDD open question resolved "lean scratch/Go" but it was answering scratch-vs-python-slim, not scratch-vs-busybox; scratch has no shell, so a terminal into the container returns 127 and Gate 1's demo cannot actually show a prompt — a fleet terminal whose own image has no shell is a footgun | scratch kept as a one-line revert in a comment for enroll/heartbeat/drop-off-only images.
- 2026-08-11 broker serves GET /agent.py alongside /agent.sh (contrib.AgentPY embed) and the panel's python block now curls it | the panel told you to run `python3 agent.py` with no way to obtain the file — broken wow-moment | shipping agent.py as a separate download rejected: the broker already embeds agent.sh, parity is one route.
- 2026-08-11 Go agent maps signal deaths to 128+N (was exec.ExitCode() == -1) via syscall.WaitStatus.Signaled() | the Python agent already reported 137 for SIGKILL, so two implementations of a frozen protocol disagreed on the same wire field; PROTOCOL.md now pins 128+N | leaving -1 rejected: "exited with -1" is a meaningless banner and the divergence would resurface in every future agent.
- 2026-08-11 PROTOCOL.md pins POPFLEET_URL as a base URL (agents append /ws/agent, http->ws) | undocumented in both RDD and protocol; the Python agent first required a full path, which would break every copy-pasted panel block | (none).
- 2026-08-11 no frame-ancestors / X-Frame-Options on /term/{sid}, stated as deliberate in PROTOCOL.md | the RDD's entire integration surface is "open the session URL in an iframe" from the operator's own apps; frame-ancestors 'self' would break it, and the one-time 60 s key is the actual guard | locking framing rejected on those grounds, revisit if session keys ever become reusable.
- 2026-08-11 removed a stray .omc/ hook-state tree that tooling had written inside internal/panel/vendor/ | it was source-tree pollution and the reason panel.go embeds named files rather than the directory | named-file embed kept anyway: it cannot silently swallow junk.
- 2026-08-11 broker serves a copy of its own executable at GET /bin/popfleet-{goos}-{goarch} (os.Executable + http.ServeFile), exact-name match only | operator hit a hard failure on the quickstart: agent.sh fetched a GitHub release URL that 404s because no release has ever been cut, so agent.sh enrollment was dead on arrival for a self-hosted broker; the broker IS the agent binary, so it can hand out a copy for same-platform boxes and the release dependency disappears | cross-compiling on demand rejected (needs a Go toolchain on the broker); embedding all platform binaries rejected (4x binary size for a personal tool).
- 2026-08-11 agent.sh tries $URL/bin/... then the GitHub release, POPFLEET_BIN_URL overrides both, and a total miss removes the tmp file and exits 1 with cross-compile instructions | a half-installed binary plus a raw curl 404 is the worst possible failure for a paste-one-line install | silent GitHub-only fetch rejected: it is the bug that was reported.
- 2026-08-11 /bin/{name} compares against "popfleet-"+GOOS+"-"+GOARCH by exact string, never joins the request into a path | path traversal is then structurally impossible rather than filtered; %2F-encoded traversals stay inside one path segment and reach the handler decoded, so router cleaning is NOT the guard | serving from a directory root rejected: that would need traversal defence instead of an equality check.
- 2026-08-11 release workflow (tag v*) runs gofmt/vet/test -race as a gating job before any publish | a broken tag is worse than no tag; binaries and image jobs both `needs: test` | publish-then-yank rejected: agent.sh pulls releases/latest blind.
- 2026-08-11 release assets are RAW binaries named popfleet-<os>-<arch> (linux/darwin x amd64/arm64) plus checksums.txt, built CGO_ENABLED=0 -trimpath -ldflags "-s -w" | agent.sh curls releases/latest/download/popfleet-$OS-$ARCH straight to disk and chmods it, so a tarball would be silently installed as the binary | goreleaser rejected: archives-by-default plus a config file for a two-binary project.
- 2026-08-11 agent.Version const -> var "dev", stamped via -X github.com/ejoliet/popfleet/internal/agent.Version=<tag-without-v> in release workflow and Containerfile ARG VERSION | hardcoded 1.0.0 meant every agent forever reports 1.0.0 in the panel; unstamped dev builds now say "dev" instead of a fake number | keeping a bumped const rejected: releases would drift from tags the first time someone forgets.
- 2026-08-11 release workflow pushes multi-arch (amd64+arm64) image to ghcr.io/ejoliet/popfleet-agent:<ver> and :latest with GITHUB_TOKEN packages:write; panel podman block now names that image | panel previously emitted popfleet/agent, an image that exists nowhere — zero-friction hole | Docker Hub rejected: needs a PAT secret the operator must create; GHCR rides the built-in token.
- 2026-08-11 separate ci.yml on push/PR to main: gofmt -l gate, vet, build, test -race, python3 -m py_compile contrib/agent.py, ubuntu-latest only | fast pre-merge signal incl. the Python agent's syntax; cross-compile correctness is the release job's problem | matrix CI rejected: pure-Go cross-builds don't need per-OS runners every push.
- 2026-08-11 Containerfile build stage is FROM --platform=$BUILDPLATFORM with GOOS/GOARCH from TARGETOS/TARGETARCH | buildx would otherwise run the entire Go toolchain under QEMU for the arm64 leg of the multi-arch release image, turning seconds into minutes; defaults (TARGETOS=linux, empty TARGETARCH) keep a plain `podman build`/`docker build` working | emulated build accepted-and-moved-on rejected: it is three lines to fix and every release pays the cost.
- 2026-08-11 GATE 1 VERIFIED with docker (8.72 MB image): container start -> panel online in 0.50 s (spec <5 s); terminal into the container returned a real busybox prompt with 40 ms to first byte and exit 0 (this is exactly what FROM scratch would have made impossible, returning 127); docker kill -> red dot in 0.20 s (spec ~25 s, faster because the broker sees the socket drop rather than waiting for missed heartbeats); docker start -> same machine id 383661907876f376, online, no re-enroll.
- 2026-08-11 docs restructured: README is the user landing page, the v1 RDD moved verbatim to docs/RDD.md and the hand-run gate checklist to docs/GATES.md | a first-time reader hit 140 lines of spec before the quick start, and the design record is a record rather than an onboarding path | rewriting the RDD into prose rejected: every word of the spec survives as written.
